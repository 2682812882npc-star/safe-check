# U04 密码最长有效期

## 来源与范围

原包《Ubuntu_安全加固_手工命令学习记录》§30；对应G02-025。以下“结果”为原笔记记载，本次没有重跑目标机。

## 问题与判断

默认PASS_MAX_DAYS及所查已有账号原均为99999，超过本项目1～365天要求。login.defs默认值不会自动同步已有账号。

## 整改方法

先记录原值、系统日期和最近改密日期，避免设置后立即过期。备份login.defs并核对；原记录中备份核对及日期输出没有回传。默认配置改为365，再单独调整已有获准实验账号：

```bash
chage -M 365 labadmin
```

labadmin为示例账号；-M不修改密码内容，也不重置最近改密日期。

## 复测方法

```bash
chage -l labadmin
grep -nF 'PASS_MAX_DAYS' /etc/login.defs
```

核对未注释默认行和所选账号Maximum number of days均为365；不把密码过期后失效或账号到期字段混为最长有效期。

## 已记录结果

原笔记记录两处均365天。所查账号最近改密日期未变化，到期按最近改密日期加365天计算；最短0、提醒7等原值保持。

## 回退

需要撤销时，默认配置用本次核对的备份/原值恢复；所选账号单独用`chage -M 99999 labadmin`恢复原最长天数。只恢复login.defs不能回退已有账号字段。此项回退未执行。

## 验证边界

仅默认及所选账号配置复查通过；未扩展到所有账号，未做实际登录或sudo执行验证。原记录未提供部分准备步骤及退出码，不补造。
