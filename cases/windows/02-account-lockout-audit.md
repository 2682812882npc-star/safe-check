# W02 账户锁定审核

## 来源与范围

原包《安全加固 Windows 2019》“第5组：登录审核”；Adv Audit Config行24/30/33。以下“结果”为原笔记记载，本次没有重跑目标机。

## 问题与判断

原账户锁定审核为成功，所选基线要求失败；登录为成功和失败，特殊登录为成功。这里只改偏差项。

## 整改方法

在secpol.msc → 高级审核策略配置 → 系统审核策略 → 登录/注销 → 审核账户锁定，保存原值，将所选项设为失败。其他两项保持。

## 复测方法

```powershell
auditpol /get /subcategory:* /r
```

按名称及对应GUID查找Account Lockout、Logon、Special Logon，核对有效值分别为Failure、Success and Failure、Success；本地化名称不同应按GUID对应。

## 已记录结果

原笔记记载三项生效审核策略均符合本组要求，配置复测通过。

## 回退

预案：按已保存的原值恢复选定子类别并再次查询；不要恢复整个旧策略覆盖其他变更。本案例未完成回退验证。
